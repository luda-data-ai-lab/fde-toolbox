# SpecForge

과제 산출물을 모아 AI 코딩 에이전트(Devin 등)에게 넘길 **Spec.md**와 **Devin.md**를 만드는 도구입니다. LUDA 문서 템플릿의 섹션에 DiscoveryQ 인사이트, FlowDesk 흐름도, I/F 목록, OntoMap 용어 사전, 자유 입력 요구사항을 규칙에 따라 채워 초안을 만들고(LLM 없이), 편집·버전 저장·비교 후 내려받습니다.

## 문서 조립하기

1. 위쪽에서 고객사와 **인게이지먼트**를 고릅니다. 인게이지먼트를 고르지 않으면 새 문서를 만들 수 없습니다.
2. **새 문서 조립**에서 **문서 종류**(Spec.md/Devin.md)와 제목을 정합니다. **템플릿**은 문서 종류에 맞는 LUDA 템플릿 중에서 고릅니다.
3. **규칙팩**을 고릅니다. 규칙팩의 규칙은 Devin.md의 "작업 규칙" 섹션에 그대로 들어갑니다.
4. **입력 선택**에서 넣을 산출물을 고릅니다.
   - DiscoveryQ 세션: 세션 요약과 인사이트가 "기능 명세"에, 액션 아이템이 Devin.md "작업 단계"에 들어갑니다.
   - FlowDesk 흐름: 레인, 주요 단계, 관련 시스템이 "전체 구조"에 들어갑니다.
   - I/F 목록: 고객사의 I/F가 표로 "전체 구조"에 들어갑니다.
   - OntoMap 용어 사전: 확정 용어와 부서별 호칭이 Spec.md "용어 정의"에 표로 들어가고, Devin.md "데이터 모델"에는 "데이터 모델은 이 용어를 따른다"는 지시와 용어 표가 들어갑니다.
5. 필요하면 **자유 입력 요구사항**을 적습니다. "개요"(Devin.md는 "목표") 섹션에 들어갑니다.
6. **초안 조립**을 누르면 편집 화면이 열립니다.

입력이 없는 섹션에는 템플릿의 작성 규칙이 `> TODO: …`로 남습니다. 같은 인게이지먼트의 산출물만 고를 수 있습니다.

## 편집과 미리보기

왼쪽 **Markdown 편집**에서 고치면 오른쪽 **미리보기**에 바로 보입니다. 위쪽 **저장**을 눌러야 서버에 저장됩니다. 저장하지 않은 변경이 있으면 "저장하지 않은 변경이 있습니다."가 표시됩니다.

**다시 조립**은 처음 고른 입력으로 초안을 새로 만듭니다(그사이 추가된 인사이트·용어가 반영됩니다). 편집한 내용이 바뀌므로 먼저 버전을 저장하세요.

## 버전과 비교

- **버전 저장**: 현재 저장된 내용을 v1, v2 … 로 남깁니다. 메모를 붙일 수 있습니다.
- **복원**: 고른 버전의 내용으로 문서를 되돌립니다.
- **비교 기준/비교 대상**: 두 버전, 또는 버전과 **현재 편집본**의 차이를 줄 단위로 보여 줍니다(추가는 초록, 삭제는 빨강).

## 보강 (LLM 또는 프롬프트 복사)

**프롬프트 만들기**를 누르면 현재 문서를 다듬어 달라는 프롬프트가 만들어집니다. 섹션 구조와 작업 규칙은 바꾸지 말고, 문서에 없는 내용은 지어내지 말라는 지시가 들어 있습니다.

- LLM 어댑터가 꺼져 있으면(기본): **복사**로 프롬프트를 복사해 승인된 외부 도구에서 실행하고, 결과를 **결과 붙여넣기**에 넣은 뒤 **편집기에 적용**을 누릅니다.
- LLM 어댑터가 승인·활성화되어 있으면 **LLM으로 보강** 버튼이 나타납니다. 결과는 저장되지 않은 변경으로 편집기에 들어가니, 확인한 뒤 **저장**하세요. 호출은 감사 로그에 남습니다. 어댑터 설정은 [외부 연동](/manual/adapters)을 보세요.

## 확정과 내보내기

- **확정**을 누르면 상태가 "확정"이 됩니다. 다시 고치려면 **초안으로 되돌리기**를 누릅니다.
- **Spec.md 내려받기 / Devin.md 내려받기**로 문서 하나를 받습니다.
- 목록의 **ZIP 내보내기**는 고른 인게이지먼트(고르지 않으면 고객사 전체)의 문서를 한 ZIP으로 받습니다. 같은 종류가 여러 개면 `Spec-2.md`처럼 번호가 붙습니다.

## 권한

| 역할 | 할 수 있는 일 |
| --- | --- |
| LUDA 관리자, FDE | 조립, 편집, 버전, 보강, 확정, 삭제, 내보내기 |
| 고객사 관리자 | 보기, 내보내기 |
| 고객사 사용자 | 보기 |

모든 생성·수정·버전·복원·보강·내보내기는 [감사 로그](/manual/workspace)에 남습니다.

## 다른 모듈에서 받기와 DevTracker로 보내기

- DiscoveryQ 세션, FlowDesk 흐름, 확정된 ExMigrate ERD, I/F 관리, OntoMap 용어 사전 화면의 **SpecForge로 보내기**를 누르면 새 문서 조립 화면이 해당 입력이 선택된 상태로 열립니다. 다른 입력도 더 고를 수 있습니다.
- **ExMigrate ERD**: 같은 인게이지먼트에서 ERD를 확정한 분석만 목록에 나옵니다.
- 문서를 **확정**하면 편집 화면에 **DevTracker로 보내기**가 나타납니다. 누르면 DevTracker 프로젝트 등록 화면이 문서 제목과 인게이지먼트로 채워지고, 등록하면 이 문서가 프로젝트에 연결됩니다. 확정되지 않은 문서는 연결할 수 없습니다.
