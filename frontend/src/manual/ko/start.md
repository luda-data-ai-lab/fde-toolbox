# 시작하기

FDE Toolbox는 고객사 현장의 FDE가 **진단 → 분석 → 설계 → 구축 → 운영** 단계를 한 인게이지먼트(과제) 안에서 이어서 다루는 도구입니다. 모든 데이터는 고객사 단위로 분리되어 저장되고, 기본 설정에서는 외부로 아무것도 전송하지 않습니다.

## 로그인

1. 관리자에게 받은 이메일과 비밀번호로 로그인합니다.
2. 오른쪽 위에 이름과 역할이 표시됩니다. 작업이 끝나면 **로그아웃**을 누릅니다.

## 화면 구성

- **왼쪽 메뉴**: 단계별로 묶여 있습니다. 진단(DiscoveryQ), 분석(I/F 관리, OntoMap 용어 사전), 설계(FlowDesk, SpecForge), 구축(DevTracker), 운영(AgentHub), 공통(인게이지먼트, 시스템 레지스트리, 첨부파일, 자산 라이브러리, 감사 로그 등).
- **위쪽 고객사 선택**: 지금 작업할 고객사를 고릅니다. 모든 화면은 선택한 고객사의 데이터만 보여 줍니다.
- **위쪽 인게이지먼트 선택**: 특정 인게이지먼트로 범위를 좁힙니다. "전체 인게이지먼트"면 고객사 전체가 보입니다.
- **매뉴얼**: 지금 보고 있는 화면의 설명서를 엽니다.
- **English / 한국어**: 화면 언어를 바꿉니다. 매뉴얼도 같은 언어로 바뀝니다.

## 역할과 권한

| 역할 | 할 수 있는 일 |
| --- | --- |
| LUDA 관리자 | 모든 고객사 조회·편집, 고객사·사용자 관리, 자산 라이브러리 편집, ZIP 내보내기/가져오기 |
| FDE | 배정된 고객사에서 조회·등록·수정·삭제, 내보내기, 감사 로그 조회 |
| 고객사 관리자 | 자기 회사 데이터 조회, 내보내기, 감사 로그 조회, 외부 연동 승인 |
| 고객사 사용자 | 자기 회사 데이터 조회 |

권한이 없는 화면에서는 "권한이 없습니다."가 표시되고, 편집 버튼은 보이지 않습니다.

## 홈

홈에는 역할에 맞는 현황이 나옵니다. LUDA 관리자는 고객사·사용자·자산 수, FDE와 고객사 사용자는 진행 중·중단된 태스크와 에이전트 인스턴스 상태를 봅니다. 고객사 카드의 **이 고객사로 전환**을 누르면 위쪽 고객사 선택이 바뀝니다.

## 일반적인 진행 순서

1. [공통 화면](/manual/workspace)에서 인게이지먼트를 만들고 고객사 시스템을 등록합니다.
2. [DiscoveryQ](/manual/discoveryq)로 현업 인터뷰를 기록합니다.
3. [I/F 관리](/manual/interfaces)와 [OntoMap](/manual/ontomap)으로 시스템 연동과 용어를 정리합니다.
4. [FlowDesk](/manual/flowdesk)로 As-Is/To-Be 업무 흐름을 그리고, [SpecForge](/manual/specforge)로 산출물을 모아 Spec.md·Devin.md를 만듭니다.
5. [DevTracker](/manual/devtracker)로 구축 작업을, [AgentHub](/manual/agenthub)로 운영 중인 에이전트를 관리합니다.
