# 고객사·사용자 관리

LUDA 관리자만 쓰는 화면입니다. 왼쪽 메뉴 **공통** 아래 **고객사 관리**, **사용자 관리**에 있습니다.

## 고객사 관리

- 이름과 코드를 입력해 고객사를 **등록**합니다. 코드는 중복될 수 없습니다.
- 끝난 고객사는 **보관**하고, 필요하면 **복원**합니다.
- **삭제**하면 그 고객사의 모든 데이터가 지워집니다. 확인 창이 나옵니다.

### 고객사 이관(ZIP)

- **내보내기(ZIP)**: 고객사 데이터 전체를 ZIP 파일로 내려받습니다. 외부 연동 인증 정보는 포함되지 않습니다.
- **ZIP 가져오기**: **새 고객사 코드**를 입력하고 ZIP 파일을 고르면 새 고객사로 만들어집니다. ID는 새로 발급되고 내부 참조도 다시 연결됩니다.

다른 설치(예: 고객사 내부 서버)로 옮기거나 백업할 때 사용합니다.

## 사용자 관리

1. 이메일, 이름, 역할, 비밀번호(8자 이상)를 입력합니다.
2. 고객사 관리자·고객사 사용자는 소속 고객사를 반드시 고릅니다. FDE는 담당 고객사를 배정합니다. LUDA 관리자는 모든 고객사에 접근하므로 고객사를 고르지 않습니다.
3. **등록**합니다. 목록에서 FDE의 배정 고객사를 바꾸거나, 사용자를 활성/비활성으로 바꿉니다.

역할별 권한은 [시작하기](/manual/start)를 참고하세요.
