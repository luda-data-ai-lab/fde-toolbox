# DiscoveryQ

진단 단계에서 현업 인터뷰를 준비하고 기록하는 도구입니다. 질문 뱅크에서 질문을 골라 세션 워크시트에 답변·인사이트·액션 아이템을 남기고, Word 보고서로 정리합니다.

> 먼저 위쪽에서 고객사를 고르세요. 세션과 대상자는 인게이지먼트에 속하므로 인게이지먼트가 하나 이상 있어야 합니다.

## 탭 구성

| 탭 | 내용 |
| --- | --- |
| 세션 | 인터뷰·코칭 세션 목록과 워크시트 |
| 대상자 | 인터뷰 대상자(이름, 부서, 직책, 담당 시스템) |
| 질문 뱅크 | LUDA가 배포한 표준 질문 모음 |
| 고객사 질문 | 이 고객사용으로 복사하거나 직접 작성한 질문 |
| 액션 아이템 | 모든 세션에서 나온 후속 조치 |

## 대상자 등록

1. **대상자** 탭에서 인게이지먼트를 고르고 이름, 부서, 직책, 담당 시스템을 입력합니다.
2. **대상자 등록**을 누릅니다.

## 세션 진행

1. **세션** 탭에서 **새 세션**을 누르고 인게이지먼트, 대상자, 제목, 일자, 세션 유형(현장 인터뷰/코칭)을 입력합니다.
2. 목록에서 **워크시트 열기**를 누릅니다.
3. **질문 선택**에서 질문 뱅크나 고객사 질문을 고르거나, **직접 질문 입력**에 질문을 써서 **추가**합니다.
4. 질문마다 **답변**을 적습니다. 입력 칸을 벗어나면 저장되고 "저장됨"이 표시됩니다.
5. 답변에서 얻은 통찰은 **인사이트 추가**, 후속 조치는 **액션 추가**로 남깁니다. 질문에 묶이지 않는 내용은 **기타 인사이트**에 적습니다.
6. 인터뷰가 끝나면 세션 상태를 "완료"로 바꿉니다.

## 답변에서 용어 등록

답변 안의 업무 용어를 바로 [OntoMap](/manual/ontomap) 후보로 보낼 수 있습니다.

1. 답변 칸에서 용어로 등록할 표현을 마우스로 선택합니다. **용어 후보** 칸에 자동으로 채워집니다.
2. **용어로 등록**을 누르면 "후보로 등록됨"이 표시되고, 아래 "이 세션에서 등록한 용어 후보" 목록에 추가됩니다.
3. 후보는 OntoMap › 후보 탭에서 확정하거나 기존 용어에 병합합니다.

## 질문 관리

- **질문 뱅크** 탭에서 카테고리·대상으로 질문을 찾고, **고객사 질문으로 복사**로 이 고객사 전용 질문을 만듭니다.
- **고객사 질문** 탭에서 **고객사 질문 등록**으로 직접 작성하거나, 복사한 질문을 고객사 상황에 맞게 수정합니다.

## 액션 아이템

**액션 아이템** 탭에서 담당자, 기한, 상태(미착수/진행 중/완료/취소)를 관리합니다. **액션 아이템 CSV**로 목록을 내려받을 수 있습니다.

## 내보내기와 보고서

| 버튼 | 위치 | 결과 |
| --- | --- | --- |
| Markdown 내보내기 | 워크시트 | 세션 내용을 Markdown 파일로 저장 |
| Word 보고서 | 워크시트 | 세션 보고서(.docx): 질문·답변, 인사이트, 액션 아이템, 등록한 용어 |
| 진단 보고서(Word) | 세션 목록 | 인게이지먼트 전체 세션을 묶은 진단 보고서(.docx) |
| 액션 아이템 CSV | 액션 아이템 탭 | 액션 아이템 목록 |

보고서는 서버에서 바로 만들어지며 외부로 전송되지 않습니다. 내보내기는 LUDA 관리자, FDE, 고객사 관리자가 할 수 있고 감사 로그에 기록됩니다.
