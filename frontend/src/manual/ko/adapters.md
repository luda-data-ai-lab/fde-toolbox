# 외부 연동(어댑터)

LLM 같은 외부 서비스로 데이터를 보내는 기능은 어댑터를 통해서만 동작합니다. 기본 설치에서는 외부 연동이 꺼져 있고 이 메뉴도 보이지 않습니다.

## 메뉴가 보이는 조건

서버 `.env`에 `ADAPTERS_ALLOWED=true`가 설정되어 있고, 사용자가 LUDA 관리자, FDE, 고객사 관리자 중 하나일 때 **공통 › 외부 연동(어댑터)** 메뉴가 나타납니다.

## 활성화 절차

1. **FDE**가 어댑터의 **데이터 반출 범위**(전송 대상, 반출 데이터, 사용 기능)를 확인하고, 모델·최대 토큰·타임아웃·API 키 등을 입력한 뒤 **활성화 요청**을 누릅니다. 상태가 "승인 대기"가 됩니다.
2. **고객사 관리자**가 반출 범위를 확인하고 "위 반출 범위를 확인했고 고객사로서 승인합니다"에 체크한 뒤 **승인**합니다. 맞지 않으면 **반려**합니다.
3. 고객사 관리자가 없는 단독 설치에서는 LUDA 관리자가 **승인 사유**를 반드시 적고 승인합니다.
4. 활성 상태에서 **연결 확인**으로 외부 서비스 연결을 점검합니다.
5. 더 쓰지 않을 때는 **비활성화**합니다. 반려·비활성화하면 저장된 인증 정보가 지워집니다.

## 보안

- API 키는 `.env`가 아니라 이 화면에서 입력하며, 서버에 암호화되어 저장됩니다. 화면, 감사 로그, 고객사 ZIP 내보내기 어디에도 나타나지 않습니다.
- 그래서 ZIP으로 가져온 고객사는 인증 정보가 없어 다시 활성화를 요청해야 합니다.
- 외부 호출마다 기능, 요청·응답 크기, 결과, 소요 시간이 감사 로그에 남습니다. 본문은 저장하지 않습니다.

## 연동이 꺼져 있을 때

어댑터가 활성화되어 있지 않으면 외부를 쓰는 기능은 "프롬프트 복사 모드"로 동작합니다. 화면이 만든 프롬프트를 복사해 승인된 도구에 직접 붙여넣고, 받은 결과를 다시 붙여넣는 방식입니다.
