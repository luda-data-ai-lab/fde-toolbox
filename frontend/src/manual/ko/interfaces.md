# I/F 관리

고객사 시스템 사이의 인터페이스(I/F) 목록을 엑셀로 받아 정리하고, 시스템별 송수신 현황과 연결 그래프를 봅니다.

## 탭 구성

| 탭 | 내용 |
| --- | --- |
| 목록 | I/F 검색·필터, 등록·수정·삭제 |
| 엑셀 업로드 | LUDA I/F 템플릿 업로드, 검증, 반영 |
| 대시보드 | 전체 I/F 수, 시스템별 송신·수신 건수, 상태·연동 방식 분포 |
| 연결 그래프 | 시스템을 노드로, I/F를 화살표로 그린 그래프 |

## 엑셀로 한꺼번에 등록

1. **엑셀 템플릿**을 눌러 LUDA I/F 템플릿을 내려받습니다. "인터페이스 리스트"와 "시스템 연동정보" 두 시트가 있습니다.
2. 고객사에서 받은 내용을 템플릿에 채웁니다. 주요 열은 I/F ID, I/F 명, 송신 시스템, 수신 시스템, 연동 방식(DB Link/API/파일/MQ/EAI/기타), 주기, 데이터 항목, 건수(일), 담당자, 상태(계획/개발/운영/폐기)입니다.
3. **엑셀 업로드** 탭에서 파일을 고릅니다. 행마다 검증 결과(신규/갱신/오류)와 확인 사항이 표시됩니다.
4. 시스템 레지스트리에 없는 시스템은 "미등록 시스템"으로 나옵니다. 등록할 시스템에 체크하면 반영할 때 함께 등록됩니다. 체크하지 않은 시스템을 참조하는 행은 건너뜁니다.
5. **반영**을 누르면 "반영 완료: 신규 N건, 갱신 N건, 건너뜀 N건, 시스템 등록 N건"이 표시됩니다. 같은 I/F ID는 갱신됩니다.

> 오류 행(필수 항목 누락, 알 수 없는 연동 방식·상태, 숫자가 아닌 건수, 파일 내 중복)은 반영되지 않습니다. 엑셀을 고친 뒤 다시 올리세요.

## 목록에서 직접 관리

**목록** 탭에서 시스템·상태·연동 방식으로 거르고 검색합니다. FDE와 LUDA 관리자는 행을 등록·수정·삭제할 수 있습니다.

## 대시보드와 연결 그래프

- **대시보드**: 시스템별 송신·수신 건수로 연동이 몰린 시스템을 찾습니다.
- **연결 그래프**: 시스템 간 연결을 한눈에 봅니다. **PNG 저장**으로 그림을 내려받아 보고서에 붙일 수 있습니다.

## 내보내기

**엑셀 내보내기**와 **CSV 내보내기**로 현재 목록을 내려받습니다. 셀 값이 수식으로 실행되지 않도록 처리되어 있습니다.
