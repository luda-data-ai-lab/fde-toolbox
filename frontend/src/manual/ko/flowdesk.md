# FlowDesk

업무 흐름도를 캔버스에서 그리고 고치는 도구입니다. 스윔레인(부서·역할별 가로 띠) 위에 업무 단계를 놓고 연결하며, 각 단계를 시스템 레지스트리의 시스템과 연결할 수 있습니다. 현재(As-Is)와 개선안(To-Be)을 짝으로 관리합니다.

## 흐름 만들기

1. 위쪽에서 고객사와 **인게이지먼트**를 고릅니다. 인게이지먼트를 고르지 않으면 새 흐름을 만들 수 없습니다.
2. **새 흐름**에서 제목, 구분(As-Is/To-Be), 관점(현업/PM/개발자/경영진/컨설턴트)을 정합니다.
3. **템플릿**에서 LUDA 프로세스 템플릿(예: "도료 제조 수주→생산→출하", "품질 검사 및 부적합 처리")을 고르면 레인과 단계가 자동으로 배치됩니다. 처음부터 그리려면 **빈 캔버스**를 고릅니다.
4. **등록**을 누르면 편집 화면이 열립니다.

목록에서는 인게이지먼트와 구분으로 흐름을 거를 수 있고, 짝이 있는 흐름에는 "짝 있음"이 표시됩니다.

## 캔버스 편집

| 하고 싶은 일 | 방법 |
| --- | --- |
| 단계 추가 | 오른쪽 **노드 추가**에서 유형을 고르고 **추가** |
| 단계 이동 | 노드를 끌어서 옮깁니다. 레인 위에 놓으면 그 레인에 속합니다 |
| 연결 | 노드 오른쪽 점을 끌어 다른 노드에 놓습니다 |
| 이름·유형·시스템 변경 | 노드를 클릭하고 오른쪽 **노드** 패널에서 수정 |
| 분기 조건 | 연결선을 클릭하고 **조건**을 입력 |
| 삭제 | 노드나 연결선을 선택하고 Delete 키 |
| 화면 이동·확대 | 빈 곳을 끌거나 마우스 휠, 왼쪽 아래 확대/축소 버튼 |

노드 유형은 시작, 종료, 업무, 분기, 시스템, 문서, 역할, 메모입니다. **시스템**을 고르면 노드에 시스템 약칭이 함께 표시됩니다. 목록에 없는 시스템은 먼저 [시스템 레지스트리](/manual/workspace)에 등록하세요.

**스윔레인** 패널에서 레인 이름을 입력해 **추가**하거나 **삭제**합니다. 레인을 지우면 그 레인의 노드는 레인 없이 남습니다.

변경한 뒤에는 위쪽 **저장**을 누르세요. 저장되면 버튼이 "저장됨"으로 바뀝니다.

## As-Is / To-Be 짝

- As-Is 흐름에서 **To-Be 만들기**를 누르면 현재 그래프를 복사한 To-Be 흐름이 만들어지고 바로 열립니다. 반대로 To-Be에서는 **As-Is 만들기**가 나옵니다.
- 짝이 있으면 **To-Be 열기** / **As-Is 열기**로 오갑니다.
- 한쪽 흐름을 삭제하면 다른 쪽의 짝 연결도 풀립니다.

## 스냅샷

중요한 시점(인터뷰 직후, 고객 검토 전 등)의 그래프를 버전으로 남깁니다.

1. 먼저 변경 사항을 저장합니다. 저장하지 않은 변경이 있으면 스냅샷을 만들 수 없습니다.
2. **스냅샷 메모**를 적고 **스냅샷 저장**을 누르면 v1, v2… 번호가 붙습니다.
3. **복원**을 누르면 캔버스가 그 버전으로 돌아갑니다. 저장하지 않은 변경은 사라집니다.

## 내보내기와 가져오기

| 버튼 | 결과 |
| --- | --- |
| JSON | 흐름 전체(제목, 구분, 관점, 그래프)를 JSON 파일로 저장. 다른 고객사나 설치에 다시 가져올 수 있음 |
| Mermaid | Mermaid `flowchart` 텍스트(.mmd). 레인은 subgraph로, 연결 시스템 이름 포함 |
| SVG | 벡터 그림. 문서에 넣어도 깨지지 않음 |
| PNG | 이미지 파일 |

목록 화면의 **JSON 가져오기**로 JSON 파일을 선택하면 현재 인게이지먼트에 새 흐름으로 등록됩니다. 다른 고객사의 시스템 연결은 가져오지 않습니다.

> 그림 내보내기(SVG/PNG)는 브라우저 안에서 만들어지고, JSON·Mermaid 내보내기는 감사 로그에 기록됩니다. 어느 쪽도 외부로 전송되지 않습니다.
