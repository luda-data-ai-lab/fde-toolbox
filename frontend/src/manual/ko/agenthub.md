# AgentHub

운영 단계에서 고객사에 배포한 AI 에이전트를 관리하는 레지스트리입니다. 에이전트를 직접 실행하지는 않고, 템플릿 버전, 평가 결과, 배포 현황을 기록합니다.

## 에이전트 템플릿

- **에이전트 템플릿**은 LUDA 자산 라이브러리에 있는 재사용 가능한 에이전트 정의입니다. 목록에서 템플릿을 누르면 버전별 시스템 프롬프트와 변경 사유를 볼 수 있습니다.
- 버전을 비교해 프롬프트가 어떻게 바뀌었는지 확인합니다. 템플릿 편집은 [자산 라이브러리](/manual/workspace)에서 LUDA 관리자가 합니다.

## 평가 케이스와 평가 결과

1. 템플릿 화면의 **평가 케이스**에서 입력, 기대 결과, 판정 기준을 등록합니다.
2. 에이전트를 시험해 본 뒤 **평가 결과 기록**으로 케이스별 통과 여부를 남깁니다.
3. 평가 결과 목록에서 버전별 **통과율**을 확인합니다.

## 배포 인스턴스

1. **배포 인스턴스**에서 이름, 템플릿과 버전, 배포 형태(독립 실행/LUDA 호스팅/고객사 환경), 연결된 개발 프로젝트, 연결 시스템, 비고를 입력하고 **등록**합니다.
2. 상태(준비/시범/운영/중지)를 바꿔 가며 관리합니다. 홈 화면에 상태별 인스턴스 수가 표시됩니다.
